# 空間デザインガイドルール
## 鷹匠マンション シミュレーター — 全室実装基準

リビングのコーディネート経験から導出したルール集。
新しい部屋を設計する際は、このルールをチェックリストとして使用すること。

---

## 1. 全室共通ルール（必須）

| 優先度 | ルール | 基準値 |
|--------|--------|--------|
| **最高** | 通路幅 | ≥ 800mm |
| **最高** | 家具は壁から離す | ≥ 100mm（大型家具は ≥ 200mm） |
| **高** | 色数をまとめる | ベース 70% / アソート 25% / アクセント 5%（3〜4色） |
| **高** | 照明色温度 | 2700K〜3000K（暖色）を基本とする |
| **高** | 観葉植物を配置 | 1部屋につき最低1点・窓際コーナーを優先 |
| **中** | 家具の高さバランス | 低・中・高の家具を混在させてリズムを作る |
| **中** | フォーカルポイント | 視線が自然に向かう主役（TV・アート・窓）を1点設定 |

## 2. リビング・ダイニング ガイドルール

### 2-1. ソファ〜テレビ距離

| 測定点 | 基準 |
|--------|------|
| 座面中央（eye position）〜スクリーン面 | **2.5〜3.5m** |
| 65インチ TV 推奨 | 2.8〜3.2m |

**計算式（Three.js座標系）:**
```
sofa_eye_z = sofa_z + 0.07        // 座面中央オフセット
screen_z   = tv_z + 0.055         // TVスクリーン面オフセット
distance   = sofa_eye_z - screen_z  // ≥ 2.5 かつ ≤ 3.5
```

### 2-2. センターテーブル配置

```
sofa_back_z  = sofa_z - 0.38          // バックレスト前面(TV側)
ct_front_z   = ct_z + 0.325           // CT のソファ側エッジ
gap          = sofa_back_z - ct_front_z  // 目標: 350〜500mm
```

| スタイル | 推奨gap |
|----------|---------|
| プレミアム（余白重視） | 450〜500mm |
| ファミリー（機能重視） | 350〜400mm |

### 2-3. ラグ配置ルール

- **ラグ幅 = ソファ幅 + 左右各300mm以上**（ソファ幅2.1m → ラグ幅 ≥ 2.7m）
- **ラグ奥行き計算:**
  ```
  rug_center_z = (sofa_z - 0.12 + ct_z) / 2   // 前脚とCTの中間
  rug_extends_to = rug_center_z + 0.975         // 前脚(sofa_z - 0.12)を含む
  ```
- 前脚（TVよりの2本）はラグに乗せる

### 2-4. ダイニングチェア引き出しスペース

```
chair_x から table_center_x の距離 ≥ 900mm  （椅子センター〜テーブルセンター）
壁 or 隣接家具から chair_back まで ≥ 800mm  （通路確保）
```

### 2-5. 植栽・フロアランプ配置

| アイテム | 推奨位置 |
|----------|----------|
| 植栽 | 右壁（窓下コーナー）— `x: hw * 0.82, z: 0.7〜1.0` |
| フロアランプ | ソファ右後方 — `x: 0.58*hw, z: sofa_z + 0.8` |

### 2-6. H/I タイプ別 推奨座標早見表

**H-type (6.2m × 6.5m, hw=3.1, hd=3.25)**

| 家具 | x | z | 備考 |
|------|---|---|------|
| TVユニット | 0 | **-2.4** | 後壁から 0.85m |
| ソファ | 0 | **1.0** | 画面〜眼 3.1m |
| センターテーブル | 0 | **-0.1** | ソファback(-0.62) からgap 42cm |
| ラグ中心 | 0 | **0.45** | 前脚(0.88)〜CT(0.225)の中間 |
| 植栽 | 2.6 | 0.8 | 窓下(hw-0.5) |
| フロアランプ | 1.8 | 1.8 | ソファ右後方 |

**I-type (7.2m × 5.0m, hw=3.6, hd=2.5)**

| 家具 | x | z | 備考 |
|------|---|---|------|
| TVユニット | 1.2 | **-2.4** | 後壁際 |
| ソファ | 1.0 | **1.0** | 画面〜眼 3.4m |
| センターテーブル | 1.0 | **-0.1** | gap 42cm |
| ラグ中心 | 1.0 | **0.45** | |
| 植栽 | 3.3 | 0.8 | 右壁窓下 |
| フロアランプ | 2.6 | 1.6 | ソファ右後方 |

## 3. 寝室 ガイドルール

### 3-1. ベッド配置

| ルール | 基準 |
|--------|------|
| ベッド両サイド通路 | ≥ 750mm（片側のみ使う場合は ≥ 500mm） |
| ベッド後方（ヘッドボード）〜壁 | 100〜150mm |
| ベッド前方（足元）〜対面壁 | ≥ 900mm |
| 窓から横方向 | ≥ 300mm（結露・直射光防止） |

### 3-2. ナイトスタンド

```
ns_z = bed_z - (bedKing奥行/2) + 0.19   // 枕元に揃える (0.2付近)
ns_x = ±(bedKing幅/2 + 0.05 + ns幅/2)   // = ±(1.05 + 0.05 + 0.23) ≈ ±1.1
```

現行値: `pos: [±1.1, 0, 0.2]` ✓

### 3-3. デスク（bedroom3）

- 窓側壁沿いに配置（採光・集中力向上）
- `rot: Math.PI/2`（壁と並行）
- デスク前通路 ≥ 800mm

### 3-4. ドレッサー

- 窓から ≥ 600mm（直射光で鏡が見えにくくなるため）
- ドレッサー前通路 ≥ 750mm

## 4. キッチン ガイドルール

### 4-1. 動線（作業三角形）

```
冷蔵庫 → シンク → コンロ の三角距離合計: 3.6m〜6.6m が理想
各辺: 1.2〜2.7m
```

現行シミュレーターでは I-type のみキッチン表示あり。

### 4-2. 通路幅

| 通路 | 最小 | 推奨 |
|------|------|------|
| カウンター前（1人） | 900mm | 1050mm |
| カウンター前（2人すれ違い） | 1200mm | 1350mm |
| アイランド周囲 | 900mm | 1050mm |

### 4-3. スツール（アイランド用）

```
スツール座面高 = アイランド天板高 - 270〜300mm
アイランド天板: 0.92m → スツール座面: 0.63〜0.65m
スツール間隔: ≥ 550mm（座面幅 + 余裕）
```

---

## 5. 浴室 ガイドルール

### 5-1. 最小通路

| 箇所 | 最小通路幅 |
|------|-----------|
| 浴槽横通路 | ≥ 700mm |
| 洗面台前 | ≥ 750mm |
| トイレ前 | ≥ 600mm |

### 5-2. 配置優先度

1. 浴槽: 奥（-z 側）に配置し、入口動線を確保
2. 洗面台: 鏡が正面から見える位置（壁際）
3. トイレ: 入口から直視されない位置に `rot: Math.PI/2` で壁向け

## 6. 3D実装チェックリスト

新しい家具・部屋を実装する前に以下を確認する。

### 座標系確認
- [ ] 原点 (0,0,0) = 床面中央
- [ ] Y軸 = 高さ方向（正が上）
- [ ] Z軸 = -方向がバックウォール（TVウォール）
- [ ] 家具底面 Y = 0（床面に接地）

### 家具サイズ確認
- [ ] ソファ: 2100×900×800mm（Sofa geometry: W2.1, D0.9）
- [ ] センターテーブル: 1150×650×290mm（CoffeeTable）
- [ ] ダイニングテーブル: 1500×850×790mm（DiningTable）
- [ ] ラグ: 2700×1950mm（Rug）
- [ ] キングベッド: 2100×2200mm（BedKing）
- [ ] セミダブルベッド: 1750×2100mm（Bed）

### NG チェック（やってはいけない）
- [ ] 家具が壁に密着（< 100mm）→ 離す
- [ ] 通路幅 < 800mm → 家具をずらす
- [ ] 植物がない → 最低1点追加
- [ ] 照明なし（夕暮れシーン）→ フロアランプ確認
- [ ] ラグ上にソファ前脚がない → rug_z を調整
- [ ] CT がソファから 600mm 以上離れている → CT を近づける
- [ ] TV〜ソファ距離が 3.5m を超えている → ソファを近づける
