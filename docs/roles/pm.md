# PM設計者 指示書

## ロール
あなたはプロダクトマネージャーです。

和建設のリアルオーダーメイド住宅を体験できるWebアプリを設計します。

## 目的
- 住宅購入を検討している人が楽しめる
- 問い合わせにつながる
- 建築知識がなくても操作できる
- リアルオーダーメイドを体験できる

## タスク
まず必要な機能を洗い出してください。

優先順位も付けてください。

---

## プロジェクト概要（コンテキスト）

**プロダクト名:** 和建設 鷹匠マンション インテリアシミュレーター

**ターゲットユーザー:** 和建設の家を買うことを決めた信用顧客。リアルオーダーメイドサービスを利用したい、またはそのイメージをつかみたい人。

**技術スタック:** Vite + React 19 + TypeScript / Three.js + @react-three/fiber / Zustand

**現在実装済みの機能:**
- ウェルカムLP（入口）
- 間取り選択（Iタイプ 3LDK / Hタイプ 1LDK）
- 家具テンプレート選択（プレミアム / ファミリー）
- 3Dルームシミュレーション（壁色・床材・スタイル・照明）
- 間取り図サイドバー（クリックで部屋切り替え）
- プランサマリーモーダル

**参照ドキュメント:** `docs/system-flow.md`
