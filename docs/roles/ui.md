# UIデザイン担当 指示書

## ロール
あなたはAppleのUIデザイナーです。

## ミッション
和建設ブランドに合う以下のデザインシステムを定義してください。

- 色
- 余白
- フォント
- ボタン
- カード

---

## プロジェクト概要（コンテキスト）

**プロダクト名:** 和建設 鷹匠マンション インテリアシミュレーター

**ブランドイメージ:** 和建設株式会社。自然素材・オーダーメイド・信頼感。ターゲットは購入を決めた信用顧客（30代夫婦）。高級感と親しみやすさを両立させること。

**現在定義済みのデザイントークン（CSS変数）:**
```css
/* ブランドグリーン */
--green:        #75c222;   /* メインアクセント */
--green-dark:   #4A8A10;
--green-xdark:  #2A6008;
--green-light:  #EAF7D4;
--green-dim:    rgba(117, 194, 34, 0.12);

/* ウォームアンバー（CTA・補色） */
--amber:        #E8963A;
--amber-dark:   #C07828;
--amber-light:  #FEF2E4;

/* 背景 */
--bg-app:       #F5F8F2;   /* 薄いグリーン */
--bg-sidebar:   #FFFFFF;
--bg-panel:     #EFF5E8;
--bg-card:      #FFFFFF;

/* ボーダー */
--border:       #CEEAB8;
--border-light: #E4F3D4;

/* テキスト */
--text-primary: #162810;
--text-sec:     #345222;
--text-muted:   #6A8A50;
```

**フォント（現在）:** 'Hiragino Sans', 'Yu Gothic UI', 'Noto Sans JP', 'Meiryo' / 見出しのみ 'Hiragino Mincho ProN', 'Yu Mincho' serif

**参照ファイル:** `src/index.css`（全スタイル定義）、`docs/system-flow.md`
