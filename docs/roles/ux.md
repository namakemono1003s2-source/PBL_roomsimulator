## プロジェクト概要（コンテキスト）

**プロダクト名:** 和建設 鷹匠マンション インテリアシミュレーター

**ターゲットユーザー:** 和建設の家を買うことを決めた信用顧客（想定: 30代夫婦）。建築知識がなくても直感的に操作できることが前提。

**現在の画面フロー:**
```
ウェルカムLP
  └─▶ 間取り選択（Iタイプ / Hタイプ）
        └─▶ 家具テンプレート選択（プレミアム / ファミリー）
              └─▶ 3Dシミュレーション画面
                    └─▶ プランサマリーモーダル
```

**3Dシミュレーション画面の構成:**
- 左サイドバー: 間取り図（クリックで部屋切り替え）
- 中央: 3Dルームビュー（ドラッグ/スクロールで視点変更）
- 右サイドバー: カスタマイズパネル（壁色・床材・スタイル・照明）
- ヘッダー: 物件情報・間取り図トグル・プラン確認・最初から

**技術スタック:** Vite + React 19 / Three.js（3D） / Zustand（状態管理）

**参照ドキュメント:** `docs/system-flow.md`
